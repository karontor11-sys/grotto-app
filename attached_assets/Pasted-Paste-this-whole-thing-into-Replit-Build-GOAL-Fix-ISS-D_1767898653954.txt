Then update *all* ISS widget keys + deferred completion keys inside render_iss_session_card() to use card_uid,
not session_id alone.

IMPLEMENTATION
Edit app.py in render_iss_session_card():
1) Define session_key + card_uid near the top (after placement_id/session_id/date_str are known).
2) Replace any key=... that uses session_id with card_uid.
3) Replace any st.session_state[...] keys that use session_id with card_uid.
4) Keep behavior dropdown keys as they are (they already include placement_id + session_key).
