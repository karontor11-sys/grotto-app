TARGET BEHAVIOR SPEC (for comparison)

A. DASHBOARD BEHAVIOR FOR COMPLETED PLACEMENTS

Completed records must always appear on their original dates

When a placement (ISS, Lunch Detention, or any Class Period Referral subtype) is marked Completed, it must always appear on the Dashboard when the user clicks the date it was served, indefinitely (even across months or years).

Completed cards on the Dashboard are non-interactive

On the Dashboard, a completed placement card should:

Appear collapsed only

Show:

Student Name

Placement Type

A red Completed status circle

NOT expand

NOT allow editing

Their sole purpose is to indicate who served a placement on that day.

Old, incomplete records

If a placement is still In Progress but the date is in the past:

The user must still be able to expand it, complete it, or override it.

Once completed, it becomes a collapsed, non-expandable red card on that date.

Dashboard access button

The Dashboard should have a visible button or link labeled:

“Completed Placements”

Clicking this should navigate to the Completed Placements page (which will function as the master archive).

B. COMPLETED PLACEMENTS PAGE – MASTER ARCHIVE

Single master archive

The existing Completed Placements page should serve as the only long-term archive for all completed placements.

Structure

The archive should be organized as:

Completed Placements (page)
▼ 2025–2026 School Year (current year expanded by default)
▼ January
▼ 10th
- [Collapsed record card]
→ Expand to view full record details
▼ February
▼ March
▼ 2024–2025 (collapsed)
▼ 2023–2024 (collapsed)

The current school year should be expanded by default.

Prior school years should be collapsed.

Card behavior in the archive

Each record in the archive should appear as a collapsed card showing:

Student Name

Placement Type (ISS, Lunch Detention, CPR + subtype)

Red Completed Circle

When expanded, the card should show full record details, including:

Student name

Grade

Homeroom teacher

Placement type & subtype

All dates scheduled (if applicable)

All dates served

Reason

Notes

For ISS:

Total days assigned

Day-of-Days summary

Make-up days & periods

Periods served

Daily points earned

Total points earned

Partial-day info if relevant

For Lunch Detention:

Scheduled dates

Served dates

Reason

Notes

For Class Period Referrals:

Subtype (Behavior, Cool-Down, Pre-Planned)

Scheduled days and periods (if relevant)

Served days

Reason

Notes

Master archive navigation from Create New Placement

The Create New Placement page should also have a visible button labeled:

“Completed Placements”

Clicking it takes the user to the Completed Placements page (master archive), with the current school year expanded.

Printing

From the Completed Placements page, the system should support:

Print by Day: Print all completed placements for a chosen date.

Print by Month: Print all completed placements for a selected month.

Printed output should include all the key fields listed above.
