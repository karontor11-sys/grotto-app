Natural-language lead-in (what we’re doing and why)

Before you deploy, you need a true clean slate—no students, no placements, no logs, no notifications, and no-school days wiped + calendar un-finalized—without touching schema or app logic.

This “Reset Test Data” tool is deliberately hard to trigger (requires a typed confirmation phrase), runs the wipe once, then hides itself automatically (no st.stop() landmine). After it runs and you confirm the app is clean, you can remove the block entirely.

✅ ACTUAL PASTE-IN CODE (Build Window)
In app.py, add a one-time “Reset Test Data” admin tool that wipes ALL data records (no schema/logic changes), including School Calendar closures, and un-finalizes all school years. It must NOT use st.stop().

Implementation requirements:
- The tool should appear only on the Dashboard page (sidebar is fine).
- Require user to type an exact confirmation phrase (e.g., RESET GROTTO) before enabling the button.
- On click, delete data from these ORM tables (order matters: logs first, then placements, then students):
  DailyLog, PointEvent, PartialDaySession (sessions), ISSSessionLog, EndOfDayProcessing, DismissedNotification,
  Assignment, Note, Placement, Student, SchoolClosure.
- Also un-finalize the calendar for all years by setting SchoolYearConfig.calendar_finalized = False and finalized_at = None
  (and/or delete SchoolYearConfig rows — but prefer un-finalize to preserve structure).
- After successful wipe:
  - show a clear success message + counts
  - set st.session_state["_reset_test_data_done"] = True so the tool hides on subsequent reruns
  - call st.rerun()
- On error:
  - rollback transaction
  - show error message
  - do NOT halt the app with st.stop()

# ==========================================================
# 🧹 ADMIN — ONE-TIME RESET TEST DATA (SAFE, NO st.stop())
# Purpose: wipe ALL test/QA data and reset School Calendar.
# After running once, this hides itself automatically.
# Remove this block after you confirm the app is clean.
# ==========================================================
if "_reset_test_data_done" not in st.session_state:
    st.session_state["_reset_test_data_done"] = False

if not st.session_state["_reset_test_data_done"]:
    with st.sidebar.expander("🧹 Admin: Reset Test Data (ONE-TIME)", expanded=False):
        st.warning("This permanently deletes ALL students, placements, logs, notifications, and school calendar closures in the current database.")
        confirm_text = st.text_input("Type exactly: RESET GROTTO", value="")
        really = st.checkbox("I understand this cannot be undone.", value=False)

        can_run = (confirm_text.strip() == "RESET GROTTO") and really

        if st.button("🚨 Reset ALL Test Data Now", disabled=not can_run, use_container_width=True):
            session = dm.get_session()
            try:
                from db_manager import (
                    DailyLog, PointEvent, PartialDaySession, ISSSessionLog, EndOfDayProcessing,
                    DismissedNotification, Assignment, Note, Placement, Student,
                    SchoolClosure, SchoolYearConfig
                )

                # Delete in safe order (children/logs → parents)
                counts = {}

                counts["daily_logs"] = session.query(DailyLog).delete(synchronize_session=False)
                counts["point_events"] = session.query(PointEvent).delete(synchronize_session=False)
                counts["sessions"] = session.query(PartialDaySession).delete(synchronize_session=False)
                counts["iss_session_logs"] = session.query(ISSSessionLog).delete(synchronize_session=False)
                counts["end_of_day_processing"] = session.query(EndOfDayProcessing).delete(synchronize_session=False)
                counts["dismissed_notifications"] = session.query(DismissedNotification).delete(synchronize_session=False)

                counts["assignments"] = session.query(Assignment).delete(synchronize_session=False)
                counts["notes"] = session.query(Note).delete(synchronize_session=False)

                counts["placements"] = session.query(Placement).delete(synchronize_session=False)
                counts["students"] = session.query(Student).delete(synchronize_session=False)

                # School calendar data wipe
                counts["school_closures"] = session.query(SchoolClosure).delete(synchronize_session=False)

                # Un-finalize ALL school years (preserve config rows)
                sy_rows = session.query(SchoolYearConfig).all()
                for cfg in sy_rows:
                    cfg.calendar_finalized = False
                    cfg.finalized_at = None
                counts["school_year_config_unfinalized"] = len(sy_rows)

                session.commit()

                st.success("✅ Reset complete. All test data removed and School Calendar un-finalized.")
                st.caption(
                    "Deleted: " +
                    ", ".join([f"{k}={v}" for k, v in counts.items()])
                )

                # Hide tool after successful run
                st.session_state["_reset_test_data_done"] = True
                st.rerun()

            except Exception as e:
                session.rollback()
                st.error(f"❌ Reset failed: {e}")

            finally:
                session.close()
# ==========================================================

Acceptance criteria:
- After running reset once, Dashboard loads with:
  - no students
  - no placements
  - no logs
  - no dismissed notifications
  - no school closures
  - school calendar not finalized (prompt appears as needed)
- The admin reset expander hides after success (because _reset_test_data_done=True).
- No st.stop() is used in this tool.
- No schema/table changes are made.
