Completed Placements page: Search should filter by student name only (not reason or other fields)

On the Completed Placements (Archive) page, the search box currently matches too broadly (including “reason” text and other fields). I want search to be limited strictly to student name only.

Rules

The search input should match only:

student first name

student last name

full name (first + last)

Search should be case-insensitive and tolerate extra spaces.

Do not match on “reason,” notes, placement type, staff name, etc.

Keep everything else about the archive page the same (expand/collapse, sorting, filters).

Acceptance tests

Searching “john” shows John Jacob even if the reason contains “john” elsewhere for other students.

Searching a word that appears only in reasons returns no results.

Searching “john jacob” works.

    def _name_matches(p: dict) -> bool:

        first = (p.get("studentFirstName") or "").strip()
        last = (p.get("studentLastName") or "").strip()
