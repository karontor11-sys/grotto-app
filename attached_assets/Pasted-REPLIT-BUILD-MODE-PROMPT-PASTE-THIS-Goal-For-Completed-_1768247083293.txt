Goal

For Completed ISS Placements (single-day and multi-day), display a session-level points breakdown calculated across the entire ISS placement, using existing point_events.

We do not want day-by-day breakdowns here. Day detail already lives on the Dashboard hover flags. Completed Placements should show one clean summary for the whole session.

What to display (ISS only)

On the Completed Placements page, under each completed ISS record, show the following list, computed across all days in the session:

Repair the harm – written — X

Repair the harm – verbal — X

Complete an assignment — X

Read a chapter — X

Meet with counselor — X

Restorative discussion — X

Helpful task — X

Grotto is clean & damage free — X

Other — X

Negative Points — X

Total Points — X

Rules

Each category shows POINT TOTALS, not counts.

Verbal apology contributes +2 per occurrence automatically (already stored that way).

Negative Points is the absolute total of all negative values.

Total Points is the net sum of all point events across the session.

Do not change DB schema.

Reuse existing point event data and category definitions.

Apply this only to ISS in Completed Placements.

1️⃣ Add this helper function to app.py

Place it near your other tooltip / breakdown helpers (you already added a daily one — this is the session-level version).

def build_iss_session_points_summary(point_events, positive_menu):
    """
    Builds a SESSION-LEVEL ISS points summary across all days in the placement.
    Returns a list of display lines with POINT TOTALS per category and Total Points.
    """

    def _clean_label(lbl: str) -> str:
        if not lbl:
            return ""
        return lbl.split(" (")[0].strip()

    # Preserve category order from the positive menu
    ordered = []
    for item in (positive_menu or []):
        code = item.get("code")
        if code:
            ordered.append((code, _clean_label(item.get("label", ""))))

    pos_points = {code: 0 for code, _ in ordered}
    neg_abs_points = 0
    total_net_points = 0

    for e in (point_events or []):
        val = int(e.get("value", 0) or 0)
        total_net_points += val

        if e.get("type") == "negative":
            neg_abs_points += abs(val)
        else:
            code = e.get("code")
            if code in pos_points:
                pos_points[code] += val

    lines = [f"{label} — {pos_points.get(code, 0)}" for code, label in ordered]
    lines.append(f"Negative Points — {neg_abs_points}")
    lines.append(f"Total Points — {total_net_points}")

    return lines
