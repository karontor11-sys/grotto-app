Bug fix: ISS future placements appearing on the wrong Dashboard date + duplicate ISS records

On the Dashboard, ISS placements scheduled to start in the future are incorrectly appearing on the current day. Example: if an ISS placement starts on January 7, it should not appear on January 6 when viewing the Dashboard for January 6.

Additionally, when viewing the true start date (January 7), the same ISS placement appears twice under ISS: one normal collapsed record and one locked (🔒) collapsed record. We only want one record.

Fix approach (very targeted):

The Dashboard ISS section is currently rendering ISS from two sources:

date-based ISS sessions, and

a separate list of scheduled ISS placements rendered as locked cards.

Remove the rendering of the separate scheduled ISS placements list from the Dashboard ISS section.

Keep rendering only the date-based ISS sessions. The existing ISS session card logic already supports a “future/scheduled/locked” display when appropriate.

Acceptance criteria:

A future-dated ISS placement does NOT appear on today’s Dashboard date.

On the first day of the placement (when viewing that date), the placement appears only once under ISS.

If that first-day record is still in the future relative to today, it may still show as locked, but only one record should be shown.

🧩 Exact paste-in patch (app.py only, targeted, no refactor)
