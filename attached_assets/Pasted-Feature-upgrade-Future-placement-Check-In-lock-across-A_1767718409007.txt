Feature upgrade: Future placement “Check-In lock” across ALL placement types/subtypes on the Dashboard

Right now, future ISS placements correctly disable the Check In button and show a message: “This ISS Session has not started yet. Check-in will be available on the start date.”

I want the same behavior across the board for all future placements and all subtypes shown on the Dashboard (Lunch Detention, Behavior Referral, Cool-Down Referral, Pre-Planned Referral, etc.).

Rules:

If a placement is scheduled for the future (its startDate is after today, or its status is scheduled), then on its Dashboard card:

Disable the Check In button.

Show a short message under the Check In area.

Use the same message everywhere (do not name the placement type):

“This session has not started yet. Check-in will be available on the start date.”

Keep the existing ISS behavior, but change its message text to the generic “This session…” version.

Do not change completion logic, points logic, or absent/no-show behavior. This is purely a future-placement Check In guardrail + message.

Acceptance tests:

Create a future Lunch Detention, Behavior Referral, Cool-Down, and Pre-Planned placement and navigate the Dashboard to that future date.

Confirm each card shows a disabled Check In button and the generic message.

Confirm non-future placements still allow Check In normally.

🧩 Exact paste-in patch (targeted edits in app.py)

Only edit app.py.
These are small inserts + a couple of line edits.

Patch B — Lunch Detention: disable Check In for future placements + show message
B1) Add “future placement” detection near the top of render_lunch_detention_card

Inside:

def render_lunch_detention_card(placement: dict, target_date: date):


Find this block:

Replace with:

student_name = f"{student['firstName']} {student['lastName']}"
date_str = target_date.isoformat()

# FUTURE PLACEMENT LOCK: disable Check In until the start date
placement_status = placement.get('status', 'active')
start_date_str = placement.get('startDate')
is_future_placement = False

    try:
        start_date_obj = datetime.fromisoformat(start_date_str).date()
        is_future_placement = start_date_obj > central_today()
    except Exception:
        is_future_placement = False

if placement_status == 'scheduled':
    is_future_placement = True

future_checkin_msg = "This session has not started yet. Check-in will be available on the start date."
