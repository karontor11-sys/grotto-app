Patch 2 — Don’t force-save an override comment when it’s missing (and don’t overwrite with None)

Right now, your DB layer always does:

log.override_comment = override_note


even if it’s empty/None — so let’s make it safe.

File: db_manager.py
Method: complete_iss_day(...) (yours starts around ~4996)

Find this block (yours is ~5088–5091):

if is_override:
    log.override_used = True
    log.override_comment = override_note


Replace with this:

if is_override:
    log.override_used = True
    if override_note:
        log.override_comment = override_note


This prevents blank/None overwrites and keeps behavior consistent with your mark_session_completed() method (which already guards with if override_comment:).
