Title: Notes Auto-Save Everywhere + Show Notes in Completed Placements

Goal: Remove manual “Cmd+Enter” saving for Notes. Notes should auto-save reliably for any placement type. Notes must persist on the active card and also appear correctly in Completed Placements.

Requirements

Implement a shared Notes widget that auto-saves when the user changes the text (and/or on blur) without requiring Cmd+Enter.

Auto-save must update the placement record in the database (single source of truth).

Completed Placements must display the saved Notes text for each record.

This should apply across ALL notes fields (LD, ISS, Behavior, Cool-Down, Pre-Planned, etc.).

Prevent excessive writes by saving only when the content actually changes (hash/compare) and optionally throttle.

Implementation steps

Add a reusable render_notes_autosave() helper in a shared utilities file (or near the top of the main Streamlit file).

Add DB function db_update_notes(placement_id, notes) (or equivalent) and call it from the helper.

Replace all existing Notes widgets with render_notes_autosave().

Ensure Completed Placements query includes notes and UI displays it.

# --- Notes autosave support ---

import sqlite3

def db_update_notes(conn: sqlite3.Connection, placement_id: str, notes: str) -> None:
    """
    Updates notes for a placement. Assumes a unified `placements` table with `id` and `notes`.
    Adjust table/column names if needed.
    """
    notes = notes or ""

    cur = conn.cursor()
    cur.execute(
        """
        UPDATE placements
        SET notes = ?
        WHERE id = ?
        """,
        (notes, placement_id)
    )
    conn.commit()

    """

        SET notes = ?

✅ PASTE-IN CODE #2: STREAMLIT NOTES AUTO-SAVE HELPER (put in your main app file)

Place this near the top of your main Streamlit file (after imports), or in a shared ui_helpers.py and import it.

import time
import hashlib
import streamlit as st

def _stable_hash(s: str) -> str:
    return hashlib.sha256((s or "").encode("utf-8")).hexdigest()

def render_notes_autosave(
    *,
    conn,
    placement_id: str,
    initial_notes: str,
    label: str = "Notes",
    height: int = 110,
    throttle_seconds: float = 0.6,
    sync_completed: bool = False,
):
    """
    A reusable notes component that auto-saves to DB.
    - Saves only when content changes (hash compare)
    - Throttles saves to avoid too-frequent DB writes
    - Optionally also updates completed table if your app uses one
    """
    if not placement_id:
        st.warning("Missing placement_id for notes autosave.")
        return ""

    # Session keys
    widget_key = f"notes_{placement_id}"
    last_hash_key = f"notes_last_hash_{placement_id}"
    last_save_ts_key = f"notes_last_save_ts_{placement_id}"

    # Initialize session state once
    if widget_key not in st.session_state:
        st.session_state[widget_key] = initial_notes or ""
    if last_hash_key not in st.session_state:
        st.session_state[last_hash_key] = _stable_hash(st.session_state[widget_key])
    if last_save_ts_key not in st.session_state:
        st.session_state[last_save_ts_key] = 0.0

    def _maybe_save():
        new_val = st.session_state.get(widget_key, "") or ""
        new_hash = _stable_hash(new_val)
        old_hash = st.session_state.get(last_hash_key, "")
        now = time.monotonic()
        last_ts = st.session_state.get(last_save_ts_key, 0.0)

        # Only save if changed and throttled
        if new_hash != old_hash and (now - last_ts) >= throttle_seconds:
            # --- DB write here ---
            db_update_notes(conn, placement_id, new_val)

            # Optional: if you have a separate completed table
            if sync_completed:
                try:
                    db_update_completed_notes(conn, placement_id, new_val)
                except Exception:
                    # If your project doesn't have completed table update, ignore
                    pass

            st.session_state[last_hash_key] = new_hash
            st.session_state[last_save_ts_key] = now

    # NOTE: Streamlit text_area typically triggers update on blur / focus change
    # and/or Ctrl+Enter depending on environment. This still removes "manual save".
    st.text_area(
        label,
        key=widget_key,
        height=height,
        placeholder="Auto-saves when you click/tap out of the box.",
        on_change=_maybe_save,
    )

    # Also run save check on every rerun (covers completion transitions / rerenders)
    _maybe_save()

    return st.session_state[widget_key]
