Route ALL ISS point adds through the global dispatcher + remove pending point consumption

This patch makes Positive/Negative dropdown selections dispatch a single targeted action (add_point) to the Dashboard-level ISS_PENDING_ACTION handler, and removes the fragile “pending_pos/pending_neg consume” logic inside each card. It also fixes the last remaining ISS session-state reads that still use session_id keys (collision-prone when session_id=None).
